# StreamCore design previews

The generated WebP images in this folder are **concept designs**, not screenshots captured from a verified production VPS. They show the approved visual direction. Counter values, third-party output toggles, scheduling and playlists visible in the mockups may not exist in the current alpha implementation.

| File | Purpose |
| --- | --- |
| `dashboard.webp` | Main RTL streaming command center |
| `channels.webp` | Channel management concept |
| `media.webp` | Media library concept |
| `mobile.webp` | Responsive mobile dashboard concept |

Do not advertise concept-only features as already implemented. See the root README for actual alpha capabilities.
